MVP Phases

Phase 1: Foundation (Week 1–2)

  • Hermes profile: repo-siteagent
  • Discovery Module: conversation → You Model
  • Content Module: headlines + about text
  • Design Module: 3 HTML variants
  • Photo Module: analyze + crop
  • Build Module: assemble deployable HTML
  • Deploy Module: push to GitHub Pages
  • Telegram bot as primary surface

Phase 2: Polish (Week 3–4)

  • Web chat frontend with live preview
  • Approval gates (You Model, design, deploy)
  • Iterate Module: feedback → update → redeploy
  • Version history + rollback
  • VPS deployment with Docker Compose

Phase 3: Product (Week 5–6)

  • Custom domain support
  • Multi-user (separate You Models)
  • Analytics (privacy-respecting)
  • Pricing/packaging exploration
